Scope: This prototype checks a limited getenv() → system() data-flow pattern. A clean result does not prove code is secure. Supported flows: direct use, SSA copies and casts, pointer offsets, and an if/else merge (PHI node). Not covered: other vulnerability types, pointer aliasing, loops through memory, calls into other functions, sanitizers.

The submitted code is compiled to LLVM IR and analyzed. It is never executed.
